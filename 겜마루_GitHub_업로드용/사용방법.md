# 겜마루 신청서 사용방법

1. 이 폴더의 **신청서 실행.cmd**를 더블클릭합니다.
2. 열린 브라우저에서 신청서를 작성하고 **신청서 제출**을 누릅니다.
3. 제출이 성공하면 **신청내역/겜마루_신청내역.xlsx**에 한 행씩 추가됩니다.
4. 실행 창에 표시되는 **운영자 주소**를 브라우저에서 열면 접수 건수를 확인하고 **전체 신청 내역 엑셀 다운로드**를 누를 수 있습니다.

엑셀은 열 제목, 필터, 첫 행 고정, 줄바꿈을 적용했습니다. 전화번호는 앞자리 0을 보존합니다. 신청내역의 JSON 파일은 재실행 후에도 누적 내역을 유지하는 원본이므로 함께 보관하세요.

엑셀 파일을 열어둔 상태에서는 새 접수가 실패할 수 있습니다. 파일을 닫고 다시 제출하세요. 실패 시 입력 내용은 유지되며, 동일 요청의 재전송은 중복 접수하지 않습니다. 서버 실행 중에는 실행 창을 열어두세요. Ctrl+C로 종료합니다.

현재 버전은 **실행한 PC에서 이용하는 로컬 접수 프로그램**입니다. HTML 파일만 열면 서버 저장이 되지 않습니다. 여러 신청자가 각자의 기기에서 온라인 접수하려면 서버 배포와 운영자 인증 설정이 필요합니다. 운영자 주소는 타인에게 공유하지 마세요.

현재 PC에서는 Codex에 포함된 Node.js를 사용합니다. 다른 PC로 옮길 경우 Node.js를 설치한 후 같은 폴더 구성을 유지하여 실행하세요. 신청자의 실제 개인정보는 테스트 데이터 없이 빈 엑셀부터 저장됩니다.

# 겜마루 동아리 신청서

개인정보와 지원 내용을 2단계로 입력하고 서버에 접수합니다. 운영자는 전체 내역을 Excel 파일로 다운로드할 수 있습니다.

## 로컬 실행

Node.js 20 이상을 설치하고 저장소 폴더에서 실행합니다. 추가 패키지 설치는 필요하지 않습니다.

```sh
npm start
```

신청서 주소: http://127.0.0.1:8766

운영자 주소는 실행 창에 표시됩니다. Windows에서는 `신청서 실행.cmd`를 더블클릭해도 됩니다.

## 저장

- `신청내역/applications.json`: 재실행 후에도 유지되는 신청 원본
- `신청내역/겜마루_신청내역.xlsx`: 누적 Excel 파일
- 운영자 화면의 다운로드는 다운로드 시점 전체 내역을 반환합니다.
- Excel 파일을 열어두면 새 접수가 실패할 수 있습니다. 닫고 다시 제출하세요.

신청내역과 개인정보는 GitHub에 올리지 않습니다. `.gitignore`가 해당 파일을 제외합니다. GitHub 웹 업로드 시에도 제외 여부를 직접 확인하세요.

## 개발

- `gammaru-application.html`: 신청서 디자인과 제출 동작
- `application-server.cjs`: 저장, 입력 검증, 운영자 화면, Excel 생성
- `start-application.ps1`: Windows 실행

```sh
npm run check
```

코드를 수정한 뒤 서버를 재시작하고 제출·운영자 다운로드를 확인하세요.

## 온라인 배포

현재 버전은 로컬 실행용입니다. GitHub 업로드만으로 온라인 접수 서버가 생성되지는 않습니다. 온라인 배포 전에는 외부 접속 주소, 영구 저장 공간, 운영자 인증을 설정해야 합니다. GitHub Pages에서는 이 Node.js 서버를 실행할 수 없습니다.
